# Web Designing

This repository documents my journey of learning web designing. I am using it to
practice HTML, record what I learn, and share my work publicly as it develops.

## What I am learning

The repository currently focuses on introductory HTML, including:

- Basic HTML document structure
- Headings, paragraphs, and line breaks
- Forms and common form controls
- Simple accessibility and semantic HTML practices

## Repository structure

| Path | What it contains |
| --- | --- |
| [`DemoFile.html`](DemoFile.html) | My first basic HTML page |
| [`BasicForm.html`](BasicForm.html) | A student registration form exercise |
| [`Lab-1/Header.html`](Lab-1/Header.html) | An exercise demonstrating heading levels |
| [`Lab-1/Paragraph.html`](Lab-1/Paragraph.html) | An exercise demonstrating paragraph content |

## How to view the exercises

1. Clone or download this repository.
2. Open any `.html` file in a web browser.
3. Read the source code and change it locally to experiment.

No build tools or dependencies are required for the current exercises.
